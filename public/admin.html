How it works

This admin page saves your changes in localStorage in the browser. Your portfolio index.html reads that saved data automatically when it loads. That means: 1. Open admin.html 2. Edit your content 3. Click Save Changes 4. Refresh index.html If you move the site to another browser or device, you need to re-save the data there, or later connect it to a real database.
